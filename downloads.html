Before you install

System requirements

  • Operating system64-bit Windows, Linux, or macOS
  • Memory1 GB minimum, 16 GB recommended for large studies
  • JavaJava 21. Install a compatible runtime if the package you choose omits it.
  • GraphicsNo dedicated GPU required
