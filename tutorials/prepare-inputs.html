Tutorial 02

Prepare the files LipidProphet needs.

Understand the standard input fields, select the generated TargetDB profile, and run a preflight check before processing.

  • Beginner
  • About 15 minutes
  • LipidProphet 1.0
  • Reviewed 30 Aug 2026

The standard input map

LipidProphet combines search-engine results and a sample list with a TargetDB profile, a workspace file, and an output path. The exact search-result columns depend on the source workflow, but the file roles stay the same.

Workspace file
An input_values.txt file that loads or records the paths and standard settings used for the run.
Search results
One or more .tab or .txt files. All files in one run must use the same extension and source format.
Sample list
One .xlsx workbook mapping result files and experimental samples.
TargetDB profile
The LC-MS, Direct-infusion MS, or MS-imaging profile that defines the target space used for processing.
Output
A new writable .tab path for confidence-scored results.

1. Search-engine results

  1. Export one consistent format

    Use the matching tutorial for LDA2, MS-DIAL, or ALEX123 direct infusion. Do not mix formats in a run.

  2. Keep the file extension consistent

    All selected files must end in .tab or all must end in .txt.

  3. Check identifiers

    Sample names, lipid/adduct labels, and result filenames must agree with the sample list and selected TargetDB profile.

2. Sample list

The sample list is an Excel workbook that connects selected result files to their experimental context.

  • The sample list ends in .xlsx
  • Workbook headers have not been renamed
  • Each selected result file maps to a sample
  • Sample identifiers match the result filenames
  • Each result is represented exactly once

3. Select the TargetDB profile

Select the profile that matches the experiment: LC-MS, Direct-infusion MS, or MS imaging. For negative-mode targets, select Acetate ions present only when acetate was used; otherwise LipidProphet uses formate for the affected ions.

Profile choice changes the target space

Do not select Direct-infusion MS merely because the instrument acquired MS² data. The profile must match the analytical workflow used to generate the search results.

4. Organize the analysis folder

my-study/
├── inputs/
│   ├── search-results/
│   └── sample-list.xlsx
├── workspace/
│   └── input_values.txt
└── results/
    └── lipidprophet_results.tab

Relative organization makes handoff easier, but saved workspace paths may still be absolute. Avoid moving the folder after validating the workspace.

5. Preflight checklist

  • Every input path points to a readable file
  • Search result files use one extension and one format
  • The sample list is an .xlsx workbook
  • The generated TargetDB profile matches the acquisition
  • The acetate/formate choice matches the method
  • The workspace path ends in .txt
  • The output folder exists and is writable
  • The output filename ends in .tab
Expected result

A complete, internally consistent standard input set that can be saved as an input_values.txt workspace and reused for GUI or CLI processing.
