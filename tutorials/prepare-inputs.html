Prepare your own measurements for scoring.

Bring the search results, a sample list that identifies your replicate measurements, and the acquisition settings used to collect them.

  • Beginner
  • LipidProphet 1.0

What goes into a run?

LipidProphet uses your search engine’s candidate identifications and a matching spectral library to determine which fragments to expect. The built-in TargetDB profile sets up the target database for the acquisition.

On Input / Compute, select a workspace file (.txt), your sample list (.xlsx), the search results, and an output file (.tab). The workspace records the file paths and settings so you can repeat the run.

Export one search format per run

Lipid Data Analyzer
Use the rdb export in LDA’s statistical analysis view. One summary can contain many raw measurement IDs. LDA workflow
ALEX123
Select the RDB .tab files carrying precursor and fragment evidence. One RAW_ID in the sample list identifies one measurement. Shotgun workflow
MS-DIAL
Export Peak list → Text for each individual analysis. LipidProphet uses the .txt filename stem to match that measurement to the sample list. MS-DIAL workflow

Use results from other search engines

Export each measurement’s precursor and MS² fragment detections in a tab-delimited RDB (.tab). If your engine uses a different format, convert its output to match an LDA or ALEX123 input table. The liver study packages provide examples with the headers and row structure to use.

Measurements and candidates
Preserve each measurement’s RAW_ID, lipid class, species and molecular species, adduct, charge, polarity, and precursor m/z values. For LC–MS data, include the retention-time group.
Detected fragments
Supply fragment m/z values and intensities, and use ALEX123 fragment names so they match LipidProphet’s target database for that lipid, adduct, and polarity. In the LDA liver example, FA 18:2(+O){279.233} gives the fragment name followed by its m/z. See the fragment nomenclature paper by Pauling et al. (2017).
Replicate groups
Match the RAW_ID values to the SampleList worksheet and provide at least three measurements per scoring group. Set up the sample list.

To get started, contact the LipidProphet team with the name and version of your search engine and a few representative export rows. We can help map your fields and fragment labels.

Map measurements to scoring groups

Create a worksheet named SampleList in an .xlsx workbook. Give each measurement a row and use these exact column names.

RAW_ID
The measurement identifier from an LDA or ALEX123 table, or the MS-DIAL peak-list filename without .txt.
Acquisition_group
The measurement series or acquisition setup. Group measurements whose detection frequencies should be evaluated together.
Sample_type
The tissue, condition, or other biological group. Give control and treated samples distinct labels if you want their scores calculated separately.
Plan for at least three replicate measurements per scoring group.

LipidProphet scores each lipid using the measurements that share the same sample type, acquisition group, and ion polarity. It counts distinct RAW_ID values within that group.

Match the profile to your experiment

Choose LC-MS for chromatography or Direct-infusion MS for shotgun MSALL. Select Acetate ions present if your method used acetate. The other setting uses formate for the affected negative-mode targets. Use the mass tolerances from your search. See the matching settings.

MS imaging input requirements

Select MS imaging for an imaging experiment. Supply MS1 precursor and MS² fragment evidence in a supported search-engine export, a matching spectral database, and a sample list. At least three analyses per scoring group are needed for the individual-fragment confidence threshold used in the complementarity test.

Keep the workspace with its inputs

Choose a writable results folder. When you select Compute, LipidProphet saves the settings used for the run. A downloaded study provides these files in a portable folder:

lcms-liver/
  inputs/                         Search results and SampleList.xlsx
  input_values.txt                Packaged workspace
  reference/results.tab           Supplied reference output
  results/input_values.txt        Workspace opened by the app
  results/LipidProphet_results.tab

Keep the folder structure when moving a study so that its relative file paths continue to resolve.
