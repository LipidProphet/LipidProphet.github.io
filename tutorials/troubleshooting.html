Tutorial 09 · Reference

Diagnose a LipidProphet problem.

Start with the error category, check the smallest likely cause, and preserve enough detail to reproduce unresolved issues.

  • All levels
  • Reference
  • LipidProphet 1.0
  • Reviewed 30 Aug 2026

Installation or launch

Application does not start
Confirm that the build matches the OS and architecture. On macOS, distinguish Intel from Apple silicon.
Windows installer stops
Rerun the installer with administrator privileges when requested.
JAR reports Java error
Use a Java 21-compatible runtime and keep dependency JARs beside the built application as packaged.
Large run freezes or exits
Close competing applications, confirm free memory, and use the installer VM options if more heap must be allocated. About 16 GB system memory is recommended for large studies.

Missing or rejected files

Workspace does not exist
The saved path is stale or mistyped. Select the actual readable input_values.txt.
Unsupported result extension
Use .tab or .txt. All search-result files in a run must share one extension.
Sample list rejected
Confirm it is a readable .xlsx file and maps every selected result file.
Output path rejected
Choose a writable destination whose filename ends in .tab.

Parser and nomenclature errors

  1. Identify the source format

    Do not mix LDA/ALEX-style tables with MS-DIAL text exports.

  2. Restore original headers

    Re-export from the search engine rather than repairing columns by hand.

  3. Check class and adduct spelling

    Compare the result terminology with the supported nomenclature and selected TargetDB profile.

  4. Reduce to one sample

    Create a redacted minimal case that still triggers the parser error.

Minimal cases are faster to fix

Keep the header and a few representative rows, but remove confidential sample identifiers before sharing.

TargetDB profile mismatch

Expected targets are absent
Confirm the LC-MS, Direct-infusion MS, or MS-imaging profile and the acetate/formate choice.
Target setup fails
Copy the first TargetDB-related console error and confirm that the search-result nomenclature matches the selected profile.
Unexpected ambiguity
Review isomeric/isobaric partners and the built-in deterministic false-positive-control result before changing the method.

Output errors

Output directory not writable
Create/select a writable folder before running.
Output must end in .tab
Use the required extension for the main result.
File already exists
Choose a new name. CLI users can add --overwrite, but unique outputs are safer.
Saved workspace conflicts
Use a distinct .txt path; it cannot replace the source workspace or main output.

Still unresolved?

Open a GitHub issue with:

  • OS, architecture, and LipidProphet version
  • Search-engine name and version
  • Exact steps and error text
  • Generated TargetDB profile, acetate/formate choice, and key settings
  • Relevant console and log excerpt
  • Small redacted files that reproduce the issue
Do not post confidential study data

Remove participant identifiers and unrelated rows, and obtain permission before sharing unpublished inputs publicly.
