Troubleshoot a LipidProphet run.

Find the step where the run stopped. The Console tab and the file named in an error message usually point to the next check.

  • Reference
  • LipidProphet 1.0

The application does not start

Check the operating system and architecture of the download. If your package requires a separate Java installation, use Java 21. For larger studies, 16 GB of memory is recommended.

A study will not open

Choose a writable folder under Save studies in. The first download needs an internet connection. A complete study can reopen from the same folder offline. To get a fresh copy, choose a different destination and keep the old study for comparison.

A file or sample is missing

Check the SampleList sheet and its exact headers: RAW_ID, Acquisition_group, and Sample_type. Match IDs to the raw measurements in LDA or ALEX123 tables, or to the filenames of individual MS-DIAL peak lists. Review the input requirements.

The search result export is rejected

Use one supported export format per run. For MS-DIAL, choose Peak list → Text separately for each analysis. Re-export a file with its original headers if a required column is missing. The study packages contain working examples from each search engine.

Fewer candidates are retained than expected

Check the acquisition profile, adduct chemistry, and mass tolerances against the upstream method. Check that each scoring group contains at least three replicate measurements and that biological groups have distinct sample-type labels. Review matching settings.

Find the results of a completed run

For a downloaded study, look in its results folder. The supplied comparison table is in reference. If the GUI asks to replace a file, choose a different output path to keep both runs. Apply your final cutoff to the LipidProphet score column of the exported table.

Ask about an unresolved issue

For a software issue, contact Jürgen Hartler. Include your software version, operating system, search engine, the step you were trying, and the exact console error. For questions about interpreting the score, contact Christer S. Ejsing.
