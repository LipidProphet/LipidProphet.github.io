Tutorial 08

Repeat a validated run from the command line.

Use the standard GUI to validate a workspace once, then run it headlessly with the generated TargetDB, an explicit output, and a saved copy of the effective settings.

  • Advanced
  • About 15 minutes
  • LipidProphet 1.0
  • Reviewed 30 Aug 2026

Requirements

  • LipidProphet.jar and its runtime dependency JARs are available
  • Java 21 is installed or provided by the application runtime
  • A GUI-validated input_values.txt exists
  • All paths in that workspace are readable on the machine running the command
  • The output directory already exists and is writable
Arguments select headless mode

Starting the JAR without arguments opens the graphical interface. Passing arguments invokes the CLI path.

1. Check the installed CLI

java -jar LipidProphet.jar --help

The help output is the authoritative option list for your build.

2. Run the standard generated TargetDB

java -jar LipidProphet.jar --cli \
  --input-values input_values.txt \
  --target-db-source memory \
  --target-db-workflow lcms \
  --target-db-acetate false \
  --output LipidProphet_results_lcms.tab \
  --save-input-values input_values_lcms_run.txt

Keep --target-db-source memory for the documented tutorial workflows.

3. Match the standard profile

LC-MS
Use --target-db-workflow lcms.
Direct-infusion MS
Use --target-db-workflow msall.
MS imaging
Use --target-db-workflow ms-imaging.
Acetate/formate
Use --target-db-acetate true only for acetate; use false for formate.

4. Follow output safety rules

Distinct workspace
--save-input-values must not replace the source workspace.
New outputs by default
Existing result or workspace files are rejected unless --overwrite is supplied.
Required extensions
Main output must end in .tab; saved workspace must end in .txt.
Same-format results
All search-engine results referenced by the workspace must use the same supported extension.
Use --overwrite only in controlled pipelines

Prefer unique, immutable output paths. Overwrite can replace result and saved-workspace files after validation.

5. Verify completion

A successful command prints the resolved workspace, generated TargetDB source/profile, output, saved workspace, result-entry count, and elapsed time. Exit code 0 indicates success; argument/validation errors return 2, and processing failures return 1.

LipidProphet CLI
  workspace: ...
  TargetDB source: memory
  TargetDB workflow: LCMS
  output: ...
  saved workspace: ...
All done! Entries: ...; overall processing time: ...
Expected result

A new .tab result and a distinct .txt workspace containing the effective configuration used by the headless run.
