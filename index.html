Why LipidProphet

Move from a spectral match to a dataset-level confidence measure.

Conventional similarity scores assess one match at a time. LipidProphet learns from the detection frequencies of precursors and fragments across the complete dataset.

P

Probability-based scoring

Combine four subscores that use intrinsic MS² data features instead of relying only on fragment intensity similarity.

FP

Deterministic FP control

Identify false annotations caused when isomeric or isobaric true positives produce identical or closely matching fragment m/z values.

MS²

Workflow-independent

Apply the same confidence concept to LC-MS², direct-infusion shotgun MSALL, and MS imaging data with low- or high-resolution detection.

Designed for scale

A score built from the dataset, not just the spectrum.

Frequently observed fragments are less likely to be random noise. LipidProphet uses that dataset-wide evidence to calculate confidence without depending on instrument-specific intensity patterns.

This supports unsupervised processing of large studies while preserving a clear, reproducible record of the input files and settings used for each run.

Read the scientific rationale
“Universal” means applicable to MS platforms that rely on MS² data; across separation techniques, sample matrices, instruments, and supported search engines.
