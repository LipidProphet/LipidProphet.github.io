Frequently asked questions

Quick answers

Does LipidProphet replace my search engine?

No. It consumes search-engine results and adds dataset-level confidence scoring. Supported workflows include LDA, ALEX123, and MS-DIAL formats.

Can I use LipidProphet without chromatography?

Yes. The application includes target-database workflows for LC-MS, shotgun MSALL, and MS imaging.

Do I need a dedicated GPU?

No. Memory is the more important resource for large datasets; 16 GB is recommended.

Where are my settings saved?

The GUI can save the run configuration as an input_values.txt workspace. Command-line runs require a distinct path for the exact workspace used.
